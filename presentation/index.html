Topmind Presentation v0.2.5

技能名 topmind-presentation，品牌名 TopPPT HTML。HTML 和 PPTX 出自同一份内容模型：日常翻页的是 HTML，要改版式时导出可编辑 PPTX。

是什么
正式商务演示技能（TopPPT HTML）。三种成稿：台上演示、研究报告、架构说明。日常是可翻页的 HTML，需要改版式时导出可编辑 PPTX。九套风格，浅色和深色两种主题。
适合谁
要做汇报、研究报告或架构说明的人。
安装
npx skills add topmindspace/topmind-presentation --agent claude-code -g

需要 Node.js 22+。HTML 只用 Python 标准库，导出 PPTX 另需 Node。也可用 npm、Release zip 或 git clone，见 README。

HTML 顶栏工具栏

打开交付的 HTML 就能用的快捷操作。

  • 亮暗主题（T）

    浅色适合外发，深色适合大屏，按文件记忆。

  • 风格选择

    九套风格实时切换，只改视觉，不动内容。

  • 预览 PPTX（P）

    按页序列预览，可复制提示词回对话来导出。

  • PPT 生成指引（H）

    说明导出 PPTX 的两条通道与环境依赖。

  • 全屏（F）

    沉浸式演示，方向键翻页。

  • 收起工具栏（B）

    折叠成迷你条，位置按文件记忆。

完整说明和命令见仓库 README。
