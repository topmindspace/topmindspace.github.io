Topmind Presentation · v0.2.7

一份内容，翻页的 HTML 和可编辑的 PPTX。

技能名 topmind-presentation，品牌名 TopPPT HTML。HTML 和 PPTX 出自同一份内容模型：日常翻页的是 HTML，要改版式时导出可编辑 PPTX。

安装 在 GitHub 上查看
三种成稿

先定模式，再写页。

下面三张是仓库自带的示例报告首页。

九套风格

同一份文件里切换风格。

亮色适合外发，深色适合大屏。下面是三种模式和九套风格的矩阵。

HTML 顶栏工具栏

打开就能用的快捷键。

交付的 HTML 顶部自带工具栏，下面是各按钮和对应按键。

  • T亮暗主题

    浅色适合外发，深色适合大屏，按文件记忆。

  • ☰风格选择

    九套风格实时切换，只改视觉，不动内容。

  • P预览 PPTX

    按页序列预览，可复制提示词回对话来导出。

  • HPPT 生成指引

    说明导出 PPTX 的两条通道与环境依赖。

  • F全屏

    沉浸式演示，方向键翻页。

  • B收起工具栏

    折叠成迷你条，位置按文件记忆。

安装

一条命令装好。

npx skills add topmindspace/topmind-presentation --agent claude-code -g

需要 Node.js 22+。HTML 只用 Python 标准库，导出 PPTX 另需 Node。也可用 npm、Release zip 或 git clone，见 README。
