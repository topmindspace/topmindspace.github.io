Topmind Presentation · 查看最新发布 ↗

可翻页的 HTML，可编辑的 PPTX。

把材料做成可翻页的单文件 HTML。需要继续改版式时，从同一份内容导出可编辑 PPTX。也能为已有演示文稿重新排版。

安装 在 GitHub 上查看

三种成稿

先定模式，再写页。

下面三张是仓库自带的示例报告首页。

12 套风格

同一份文件里切换风格。

亮色适合外发，深色适合大屏。下面是三种模式和12 套风格的矩阵。

多图表与高密度

一页放下几张图，仍然一眼读懂。

取自仓库里 22 页的「城市公交电动化复盘」示例：仪表盘、杂志版和简单页交替出现，信息密的页后面跟一页留白。

简单版式

一个数字、一句话或一个图标，就是一页。

简单页有 12 种变体：数字、观点、段落、图标和单图，可以左对齐、居中或分栏。下面是其中四种。

已有 PPT 美化

只换版式，不改一个字。

原稿只读。新稿出来前，每个字、每个数、图表数据、图片和演讲者备注都与原稿逐项核对。一页多图改成仪表盘或双图对照，表加图改成半表半图。

HTML 顶栏工具栏

打开就能用的快捷键。

交付的 HTML 顶部自带工具栏，下面是各按钮和对应按键。

  • T亮暗主题

    浅色适合外发，深色适合大屏，按文件记忆。

  • ☰风格选择

    12 套风格实时切换，只改视觉，不动内容。

  • P预览 PPTX

    按页序列预览，可复制提示词回对话来导出。

  • HPPT 生成指引

    说明导出 PPTX 的两条通道与环境依赖。

  • F全屏

    沉浸式演示，方向键翻页。

  • B收起工具栏

    折叠成迷你条，位置按文件记忆。

安装

一条命令装好。

npx @topmindspace/topmind-presentation install

需要 Node.js 18+（npx 安装和导出 PPTX 都用它）。HTML 只用 Python 标准库。也可用 Release zip 或 git clone，见 README。
