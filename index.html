Topmind

本地优先的个人动态流。想法、剪藏和文档先记在时间轴上，文件是工作区里的 Markdown。整理和待办可以先出建议，你确认后才写入。

桌面版覆盖 macOS、Windows 和 Linux。下面这条是 macOS 的 Homebrew 安装。

安装

brew install topmindspace/tap/topmind

GitHub Releases

演示、写作、交接

三件分开安装。演示负责成稿，写作负责文章和封面，交接负责把上下文带到另一个工具。

Topmind Presentation

正式商务演示技能。三种成稿：台上讲的演示、研究报告、架构说明。日常是可翻页的 HTML，需要改版式时再导出可编辑 PPTX。九套风格在同一份文件里切换。

在线演示 风格画廊 GitHub npm

安装

npm install @topmindspace/topmind-presentation

Topmind Writing Skills

一个安装器，四件分开装。公众号从改稿到微信内联排版；X 长文把 Markdown 转成可以粘贴的文本；短文只讲透一件事；封面按 X 和公众号两种尺寸裁切。

GitHub npm

安装

npx @topmindspace/topmind-writing-skills list
npx @topmindspace/topmind-writing-skills install topmind-wechat-post
npx @topmindspace/topmind-writing-skills install topmind-x-article
npx @topmindspace/topmind-writing-skills install topmind-briefs
npx @topmindspace/topmind-writing-skills install topmind-cover

Topmind Handoff

把做事习惯、项目和记忆收成一份 Markdown（文件头加六节）。换工具时导出、对照差异，确认后再合并。不建账号，也不经过服务器。

GitHub npm

安装

npm i @topmindspace/topmind-handoff
