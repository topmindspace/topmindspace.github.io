知识管理

一个工作区，三种入口。

想法、剪藏和文档先记在时间轴上，存成工作区里的 Markdown。整理和待办先出建议，你确认后才写入。桌面版、Obsidian 插件和技能包用同一套工作区约定，换入口不用迁移文件。

Topmind 桌面版

查看最新发布 ↗
topmindspace/topmind

三栏桌面工作台：动态流时间轴加 AI 工作区，工作区有对话、建议、清单、应用四个页签。界面支持简体中文和 English。

适合谁
想要独立应用、在界面里确认 AI 建议的人。
安装
brew install topmindspace/tap/topmind

macOS 用 Homebrew 安装（Apple 芯片）。Windows 和 Linux 的 .exe、.AppImage、.deb 在 Releases 下载。

topmind-skills 技能包

查看最新发布 ↗
topmindspace/topmind-skills

给 Claude Code、Codex、OpenCode、Hermes 等宿主的技能包。日常入口只有 topmind，由它分派到捕获、整理、写作、记忆、维护和 loop 六个动作。另有微信读书、X 两个可选连接器，以及可选的记账。

Topmind Writing Skills

查看最新发布 ↗
topmindspace/topmind-writing-skills

七个写作、排版与出图技能，一个安装器，按需单装。X 稿一律纯文本：首行给结论，段落短、段间空一行，分点一律 emoji 列表符号，emoji 只用 TopMind 体系；正文单独成块可直接复制，信源、原图、说明另列，没有原图先问再配图。

适合谁
写公众号、X 长文、干货短文和段子，需要格式化、封面和长图的创作者。
安装
npx @topmindspace/topmind-writing-skills list
npx @topmindspace/topmind-writing-skills install topmind-wechat-post

把 topmind-wechat-post 换成下方任一技能名。

GitHub npm Releases

  • topmind-wechat-post

    公众号长文全流程：交付包、审校改写、质量三关、微信内联排版和发布清单。

  • topmind-x-article

    X 长文：Markdown 原稿转一键复制 HTML 与纯文本兜底，列表自动转 emoji，附封面和发布清单。

  • topmind-briefs

    干货短文：一件事讲透。默认不出 HTML，X 正文单独一块可直接复制、公众号版 Markdown 另一块；信源（含发布时间）与 1–2 张原图块外另列。

  • topmind-viral-posts

    X 段子：18 个类型 + 钩子×主体×收尾组合，段子体一句一行、行间空行，分点也用 emoji 列表；每条正文单独成块，信源、原图、内部标签另列，没有原图先问是否配图。

  • topmind-format

    格式化：现成文字转段子或格式化成短文，只动排版不改字（保真校验），列表一律改 emoji 列表符号，按 TopMind emoji 体系加点缀；结果单独成块，说明另列。

  • topmind-cover

    封面配图：22 种风格、12 种标题花式与背景库，裁出 X 长文、公众号与 X 短文 16:9 三种尺寸。

  • topmind-poster

    长图出图：HTML 排版后用无头 Chrome 2 倍截图，做榜单、信息图和海报。

  • X 文本交付规约

    所有产出 X 纯文本的技能共用一份规约：段子和短文都可分点，分点必须用 emoji 列表符号（不用 - 和 1.）；正文单独一个可直接复制的块（含来源行与话题标签），信源、原图、配图建议、内部标签、说明各自另列，多条帖子每条一块；没有原图先问要不要配图。lint 会提示正文里混入的信源、配图、说明。

  • 常见组合

    短文 → 格式化；段子 → 格式化；短文没有原图 → 封面 16:9；超过一帖 → X 长文或公众号长文；数据长图 → poster。

Topmind Presentation

查看最新发布 ↗
topmindspace/topmind-presentation

正式商务演示技能（TopPPT HTML）。三种成稿：台上演示、研究报告、架构说明。日常是可翻页的 HTML，需要改版式时导出可编辑 PPTX。九套风格，浅色和深色两种主题。

适合谁
要做汇报、研究报告或架构说明的人。
安装
npx skills add topmindspace/topmind-presentation --agent claude-code -g

需要 Node.js 22+。HTML 只用 Python 标准库，导出 PPTX 另需 Node。也可用 npm、Release zip 或 git clone，见 README。

关于本站

一个静态页面，没有跟踪。

topmindspace.github.io 是这五个项目的介绍页，由 GitHub Pages 直接从仓库的 main 分支发布。

  • 纯静态

    HTML、CSS 和原生 JavaScript，没有构建步骤和框架。不加载外部字体，不放统计脚本，也不写 Cookie。

  • 中英双语，浅色深色

    右上角切换语言和主题。主题默认跟随系统，选择保存在本机浏览器里。系统开启「减少动态效果」时，页面不做动画。

  • 版本以 Release 为准

    页面上的版本号和描述按各仓库最新 Release 与 README 核对，核对日期写在页脚。有出入时以仓库为准。
