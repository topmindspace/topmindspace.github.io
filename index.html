Topmind 桌面版 · macOS

brew install topmindspace/tap/topmind

从你要做的事开始

  • 记录与整理想法 动态流、剪藏、文档解析。整理和待办先出建议。 Topmind · topmind-obsidian · topmind-skills

知识管理

Topmind 是主线：想法、剪藏和文档先记在时间轴上，文件是工作区里的 Markdown。整理和待办可以先出建议，你确认后才写入。桌面版、Obsidian 插件和技能包使用同一套工作区约定，按习惯选一种入口即可。

Topmind 桌面版

v4.16.0 topmindspace/topmind
是什么
三栏桌面工作台：动态流时间轴加 AI 工作区，工作区有对话、建议、清单、应用四个页签。界面支持简体中文和 English。
适合谁
想要独立应用、在界面里确认 AI 建议的人。
安装
brew install topmindspace/tap/topmind

上面是 macOS 的 Homebrew 安装（安装包为 Apple 芯片版本）。Windows 和 Linux 的 .exe、.AppImage、.deb 在 Releases 下载。

Topmind Stream · Obsidian 插件

v4.18.2 topmindspace/topmind-obsidian
是什么
在 Obsidian 主区域打开动态流，右侧栏的 AI 面板有对话、建议、清单、历史四个页签。AI 提出的修改在你确认后才写入，笔记仍是库里的 Markdown。
适合谁
已经在用 Obsidian、想在库里直接用动态流的人。需要 Obsidian 1.13.0 或更高版本，仅桌面端。
安装
topmindspace/topmind-obsidian

在 Obsidian 社区插件里搜索 Topmind Stream，或用 BRAT 添加上面的仓库。

topmind-skills 技能包

v4.15.3 topmindspace/topmind-skills
是什么
给 Claude Code、Codex、OpenCode、Hermes 等宿主的技能包。日常入口只有 topmind，由它分派到捕获、整理、成稿、记忆、维护和 loop 六个动作。另有微信读书、X 两个可选连接器，以及可选的记账。
适合谁
习惯在智能体里管理笔记的人，不需要桌面版。
安装
npx @topmindspace/topmind-skills add topmindspace/topmind-skills -g

npm 安装器会把 shared/ 一并装好，并为多个宿主建立链接。

Topmind Writing Skills

v0.8.29 topmindspace/topmind-writing-skills
是什么
六个写作与出图技能，一个安装器，按需单装。
适合谁
写公众号、X 长文和短帖，需要封面和长图的创作者。
安装
npx @topmindspace/topmind-writing-skills list
npx @topmindspace/topmind-writing-skills install topmind-wechat-post

把 topmind-wechat-post 换成下方任一技能名。

Topmind Presentation

v0.2.7 topmindspace/topmind-presentation
是什么
正式商务演示技能（TopPPT HTML）。三种成稿：台上演示、研究报告、架构说明。日常是可翻页的 HTML，需要改版式时导出可编辑 PPTX。九套风格，浅色和深色两种主题。
适合谁
要做汇报、研究报告或架构说明的人。
安装
npx skills add topmindspace/topmind-presentation --agent claude-code -g

需要 Node.js 22+。HTML 只用 Python 标准库，导出 PPTX 另需 Node。也可用 npm、Release zip 或 git clone，见 README。
